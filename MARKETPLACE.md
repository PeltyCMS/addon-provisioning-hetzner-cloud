**Tagline:** Provision Hetzner Cloud services from PeltyCMS orders

## Hetzner Cloud provisioning for PeltyCMS

Create, suspend, unsuspend and terminate customer services on Hetzner Cloud when orders are paid or cancelled. Credentials stay in Pelty secrets; the module runs as sandboxed WASM.

### Features
- Create / suspend / unsuspend / terminate
- Password + package sync hooks
- Works with Pelty product module mapping
- MythicCloud panel download supported

### Requirements
- Reachable Hetzner Cloud API/panel
- API token or login configured in Pelty
